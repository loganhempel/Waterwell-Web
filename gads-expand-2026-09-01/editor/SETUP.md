# Waterwell — Google Ads Editor import

Generated by `expand.py`. Do not hand-edit these CSVs; edit the script and rerun.

**Every campaign imports as Paused.** Nothing goes live until you unpause deliberately.

## Import order (Editor: Account > Import > From file)

1. `campaigns.csv`
2. `adgroups.csv`
3. `keywords.csv`
4. `negatives.csv`
5. `ads.csv`
6. `sitelinks.csv`
7. `callouts.csv`
8. `structured-snippets.csv`

Order matters — a keyword cannot import before its ad group exists. Editor previews
every change and flags errors before you Post; read that preview, don't skip it.

`shared-negative-lists.csv` is NOT an Editor import. Shared lists must be created in
the web UI first (Tools > Shared library > Negative keyword lists), then attached to
campaigns. The per-ad-group negatives in `negatives.csv` import normally.
